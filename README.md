# README.md

# 라헬 백명진 홈페이지

아동보육학 박사 라헬 백명진님의 전문적인 원페이지 홈페이지입니다.

## 🚀 기술 스택

- **Next.js 14** (App Router)
- **TypeScript**
- **Tailwind CSS**
- **반응형 디자인**

## 📋 주요 기능

- ✅ 반응형 네비게이션
- ✅ Hero 섹션 (KPI 지표 포함)
- ✅ 소개 섹션 (차별화 포인트)
- ✅ 강의 분야별 카드
- ✅ 출간 도서 소개
- ✅ 미디어 출연 & 소셜 링크
- ✅ FAQ 아코디언
- ✅ 문의 폼
- ✅ SEO 최적화

## 🎨 디자인 특징

- **브랜드 컬러**: 라헬 그린 (#0EA47A)
- **그라데이션**: 연한 그린 계열 배경
- **타이포그래피**: Pretendard 폰트
- **애니메이션**: 부드러운 호버 효과

## 🛠 설치 및 실행

```bash
# 의존성 설치
npm install

# 개발 서버 실행
npm run dev

# 프로덕션 빌드
npm run build
npm start
```

## 📁 프로젝트 구조

```
app/
├── components/          # React 컴포넌트
│   ├── Header.tsx
│   ├── Hero.tsx
│   ├── About.tsx
│   ├── Offerings.tsx
│   ├── Books.tsx
│   ├── Media.tsx
│   ├── FAQ.tsx
│   ├── Contact.tsx
│   └── Footer.tsx
├── lib/
│   └── brand.ts        # 브랜드 변수 및 타입
├── globals.css         # 전역 스타일
├── layout.tsx          # 루트 레이아웃
└── page.tsx            # 메인 페이지
```
